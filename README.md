# Sistema-de-Gesti-n-de-Cursos-Online-LMS-
Plataforma donde un estudiante compra un curso en línea, estudia sus lecciones, presenta las evaluaciones, el sistema lo califica y cierra el curso solo y, si aprueba, descarga su certificado. El docente arma los cursos, las lecciones, los materiales y las evaluaciones; el administrador gestiona usuarios y audita pagos e inscripciones.
